2027年の干支は「丁未（ひのとひつじ）」です。60年に一度めぐってくる組み合わせで、「赤い未年」とも呼ばれます。

この記事では、丁未がどんな年なのかと、サジュ（韓国の四柱推命）の考え方で見た、日主（生まれた日のタイプ）ごとの2027年の恋愛の流れをまとめます。

## 2027年の干支「丁未」とは

干支は、10種類の「十干」と12種類の「十二支」を組み合わせたもので、全部で60通りあります。2027年はその44番目にあたる「丁未」です。

- **丁（ひのと）**：十干のひとつで、五行では「火」。ろうそくや灯火のような、やさしく照らす火を表します。
- **未（ひつじ）**：十二支のひとつで、五行では「土」。夏の終わりの、日差しを受けて温まった土を表します。

### なぜ「赤い未年」と呼ばれるの？

五行にはそれぞれ色があり、「火」は赤を表します。2027年は十干が火の「丁」なので、韓国でも「붉은 양의 해（赤い羊の年）」と呼ばれています。

同じ丁未の年は60年に一度しかめぐってきません。前回は1967年、次は2087年です。

### サジュでは「立春」から2027年になる

サジュでは、1月1日ではなく、立春（2027年は2月4日）を年の変わり目と考えます。そのため、2027年1月〜2月3日ごろまでは、まだ2026年（丙午）の流れの中にいることになります。

## 丁未はどんな雰囲気の年？

丁の火は、大きく燃え上がる太陽ではなく、手元を照らす灯火です。未の土は、ゆっくり温まった土です。

この2つから、2027年は**急な変化より、じっくり温めて育てることが実りやすい年**と読むことができます。恋愛でいえば、一気に距離を縮めるよりも、小さなやりとりを重ねて信頼を育てることが、良い流れにつながりやすいと考えられます。

## 日主別・2027年の恋愛の流れ

サジュでは、その年の十干と、自分の日主（生まれた日の十干）の関係で、一年の流れを読みます。ここでは、2027年の「丁」と各日主の関係から、恋愛のヒントをまとめました。

自分の日主がわからない人は、[相性診断](/shindan/)で生年月日を入れるとわかります。

| 日主 | 2027年のキーワード |
|---|---|
| 甲（きのえ）・大樹 | 自分らしさを表現する |
| 乙（きのと）・草花 | 楽しさとゆとり |
| 丙（ひのえ）・太陽 | 仲間とのつながり |
| 丁（ひのと）・灯火 | 自分のペースを大切に |
| 戊（つちのえ）・山 | 支え、支えられる |
| 己（つちのと）・田畑 | 直感とひとりの時間 |
| 庚（かのえ）・鋼 | 誠実さと、けじめ |
| 辛（かのと）・宝石 | 強く惹かれる縁 |
| 壬（みずのえ）・大海 | 縁が結ばれやすい |
| 癸（みずのと）・雨露 | 出会いの広がり |

### 甲（きのえ）｜大樹タイプ

甲にとって丁は、自分のエネルギーを外に表す「傷官（しょうかん）」の関係です。思っていることを言葉にしやすく、自然体の魅力が伝わりやすい年です。

**ヒント**：言いたいことが言える分、相手への指摘が強くなりすぎないように。「ありがとう」を多めに伝えると、魅力がそのまま好意として届きます。

### 乙（きのと）｜草花タイプ

乙にとって丁は、楽しむ力やゆとりを表す「食神（しょくじん）」の関係です。肩の力が抜けて、一緒にいて楽しい人として好かれやすい年です。

**ヒント**：楽しいと感じたことを、素直に相手と分け合ってみましょう。趣味や食事を通じた縁が育ちやすい流れです。

### 丙（ひのえ）｜太陽タイプ

丙にとって丁は、同じ火の仲間を表す「劫財（ごうざい）」の関係です。友人や仲間を通じた出会いが広がりやすい一方で、人と比べたくなる場面もありそうです。

**ヒント**：誰かと張り合うより、自分の気持ちに正直に。友人からの紹介や、グループでの集まりに縁があります。

### 丁（ひのと）｜灯火タイプ

丁にとって2027年の丁は、自分と同じ気を表す「比肩（ひけん）」の関係です。自立心が高まり、対等な関係を求める気持ちが強くなる年です。

**ヒント**：自分のペースを大切にしながらも、意地を張りすぎないことが鍵。「頼ってもいい」と思えると、関係がぐっと温かくなります。

### 戊（つちのえ）｜山タイプ

戊にとって丁は、自分を支えて育ててくれる「正印（せいいん）」の関係です。安心できる人や、信頼できる人との縁に恵まれやすい年です。

**ヒント**：いつも人を受け止める側の戊ですが、2027年は甘えてみるのもおすすめ。支え合える関係が育ちます。

### 己（つちのと）｜田畑タイプ

己にとって丁は、直感やひらめきを表す「偏印（へんいん）」の関係です。気持ちが内側に向きやすく、ひとりで考える時間が増えるかもしれません。

**ヒント**：直感は大切にしつつ、考えすぎたら言葉にして相手に聞いてみましょう。少し変わったきっかけの出会いにも縁があります。

### 庚（かのえ）｜鋼タイプ

庚にとって丁は、責任や誠実さを表す「正官（せいかん）」の関係です。恋愛では、真剣な関係や将来を意識した付き合いに縁がある年と読まれます。

**ヒント**：誠実な態度が、いつも以上に相手に伝わります。関係をはっきりさせたいことがあれば、落ち着いて話し合うのに向いた年です。

### 辛（かのと）｜宝石タイプ

辛にとって丁は、強い刺激を表す「偏官（へんかん）」の関係です。心が大きく動くような、印象的な出会いがあるかもしれません。

**ヒント**：強く惹かれる相手ほど、自分のペースを守ることが大切です。振り回されそうなときは、一度立ち止まって気持ちを整理しましょう。

### 壬（みずのえ）｜大海タイプ

壬にとって丁は、安定した豊かさを表す「正財（せいざい）」の関係です。さらに、壬と丁は結びつきを表す「干合（かんごう）」の組み合わせでもあり、縁が結ばれやすい年と読まれます。

**ヒント**：派手さより、堅実な積み重ねが実を結びやすい流れです。気になる人とは、日々の小さなやりとりを大切にしましょう。

### 癸（みずのと）｜雨露タイプ

癸にとって丁は、人との交流の広がりを表す「偏財（へんざい）」の関係です。出会いの機会が増え、にぎやかな一年になりそうです。

**ヒント**：たくさんの縁の中から、自分が安心できる人を見極めることが大切。誠実なやりとりを心がけると、良い関係に育ちます。

## 生まれ年の干支と「未」の関係

日主のほかに、生まれ年の干支（十二支）と2027年の「未」との関係も、ひとつの目安になります。

- **午年生まれ**：午と未は「六合（りくごう）」という結びつきの関係。人との縁がつながりやすい年とされます。
- **卯年・亥年生まれ**：卯・亥・未は「三合（さんごう）」という、力を合わせる関係です。
- **卯年・未年・亥年生まれ**：韓国で、3年続く運気の低い時期とされる「サムジェ（三災）」が、2027年で明けると考えられています。新しいことを始めやすい区切りの年です。
- **丑年生まれ**：丑と未は「冲（ちゅう）」という、動きが出やすい関係です。環境の変化が、新しい出会いのきっかけになることもあります。

## 2027年をおだやかに過ごすために

ここで紹介したのは、その年の干支と、日主や生まれ年の干支との関係から見た、一般的な流れです。サジュでは、本来は生まれた年・月・日・時間の4つの柱と、10年ごとに変わる運の流れなどもあわせて読みます。同じ日主の人でも、一人ひとりの流れは違います。

占いの結果は、自分の気持ちを整理したり、行動のきっかけにしたりするためのヒントとして受け取りましょう。
