寒さが増してくる12月。韓国では、12月14日を「허그데이（ハグデー）」と呼び、大切な人と抱きしめ合って気持ちを伝える日として楽しまれています。

「ハグなんて、照れくさくてできない」という人もいるかもしれません。でも、ぬくもりの伝え方はハグだけではありません。手をつなぐ、温かい飲み物を手わたす、そっと背中に手を添える。小さなふれあいでも、気持ちは十分に伝わります。

この記事では、韓国の毎月14日の記念日を紹介しながら、韓国の占い「サジュ（四柱推命）」の日主（生まれた日の天干）10タイプ別に、自分らしいぬくもりの伝え方をまとめました。

## 韓国では、毎月14日が「恋人の日」

韓国では、2月14日のバレンタインデーと3月14日のホワイトデーだけでなく、毎月14日に恋人の記念日があります。公式の祝日ではありませんが、若い世代を中心に、記念日ごとのデートやプレゼントが楽しまれています。

| 日付 | 記念日 | 過ごし方の例 |
|---|---|---|
| 1月14日 | ダイアリーデー | 新しい手帳を贈り合い、記念日を書きこむ |
| 2月14日 | バレンタインデー | 女性からチョコレートを贈る |
| 3月14日 | ホワイトデー | 男性からお返しを贈る |
| 4月14日 | ブラックデー | 恋人のいない人が、黒いジャージャー麺を食べる |
| 5月14日 | ローズデー | バラの花を贈り合う |
| 6月14日 | キスデー | 恋人どうしでキスをする日 |
| 7月14日 | シルバーデー | 銀のアクセサリーを贈り合う |
| 8月14日 | グリーンデー | 森や自然の中で過ごす |
| 9月14日 | フォトデー | ふたりで記念写真を撮る |
| 10月14日 | ワインデー | ワインを楽しむ |
| 11月14日 | ムービーデー | 一緒に映画を観る |
| 12月14日 | ハグデー | 抱きしめ合って、気持ちを伝える |

11月11日の[ペペロデー](/articles/pepero-day/)のように、14日以外にも韓国ならではの記念日があります。

## 12月14日は、ふたご座流星群の夜

2026年の12月14日は、三大流星群のひとつ「ふたご座流星群」が見ごろを迎える夜でもあります。国立天文台によると、もっとも多く見えるのは12月15日の0時から2時ごろ。月明かりの少ない、観察にはいい条件の年です。

あたたかい服装で、ふたりで夜空を見上げる。寒さを言いわけに寄り添えば、自然とぬくもりが伝わります。

## 日主別・ぬくもりの伝え方

ふれあい方の好みや、気持ちの伝え方は、人によって違います。日主ごとの傾向をヒントに、自分らしいぬくもりの伝え方を探してみましょう。相手の日主がわかれば、相手が喜ぶ伝え方も見えてきます。

| 日主 | ふれあいの傾向 | おすすめの伝え方 |
|---|---|---|
| 甲木（大樹） | まっすぐで、気持ちが顔に出る | 「会えてうれしい」と、まっすぐハグ |
| 乙木（草花） | 相手に合わせて、そっと寄り添う | 手をつないで、並んで歩く |
| 丙火（太陽） | 明るく、自分から近づける | 明るく、自分から腕をひろげる |
| 丁火（灯火） | こまやかで、気配りが上手 | 手袋をはずして、手を温め合う |
| 戊土（山） | 包容力があり、頼られる | 大きく包みこむように、そっと |
| 己土（田畑） | 世話好きで、尽くすタイプ | 温かい飲み物を、手わたす |
| 庚金（鋼） | 照れ屋で、気持ちを言葉にしにくい | 照れずに、短く力強く |
| 辛金（宝石） | 繊細で、雰囲気を大切にする | おそろいのマフラーを、巻いてあげる |
| 壬水（大海） | 自由で、一緒に動くのが好き | 雪の街を、腕を組んで歩く |
| 癸水（雨露） | やさしく、相手の気持ちに敏感 | 背中を、やさしくなでる |

### 木の日主（甲木・乙木）

甲木の人は、気持ちがまっすぐ顔に出るタイプ。「会えてうれしい」と言葉にしながらハグすると、気持ちがそのまま伝わります。乙木の人は、相手に合わせて寄り添うのが上手です。大げさなハグより、手をつないで並んで歩く時間が、ふたりの距離を縮めてくれます。

### 火の日主（丙火・丁火）

丙火の人は、明るく自分から近づけるタイプ。会った瞬間に腕をひろげれば、相手も笑顔になります。丁火の人は、こまやかな気配りの人。手袋をはずして、冷えた手を温め合うような、さりげないふれあいが似合います。

### 土の日主（戊土・己土）

戊土の人は、包容力のある人。大きく包みこむように、そっと抱きしめると、相手は安心できます。己土の人は、世話好きで尽くすタイプです。温かい飲み物を手わたすときに、そっと手にふれる。それだけでも、やさしさが伝わります。

### 金の日主（庚金・辛金）

庚金の人は、気持ちを言葉にするのが少し苦手な照れ屋さん。長いハグが照れくさければ、短く力強く。それだけで、気持ちは十分に伝わります。辛金の人は、雰囲気を大切にする繊細なタイプ。おそろいのマフラーを巻いてあげるなど、思い出に残るふれあいを選びましょう。

### 水の日主（壬水・癸水）

壬水の人は、一緒に動きまわるのが好きなタイプ。雪の街を腕を組んで歩けば、楽しい時間がぬくもりに変わります。癸水の人は、相手の気持ちに敏感なやさしい人。言葉にしなくても、背中をそっとなでるだけで、相手は安心できます。

## ひとりのハグデーも、ぬくもりの日に

恋人がいない人も、ハグデーは「ぬくもりを感じる日」にできます。家族や友人に、いつもありがとうと伝える。温かいお風呂にゆっくりつかって、自分をいたわる。それも立派なハグデーの過ごし方です。

失恋したばかりで、さみしい気持ちが強いときは、[失恋から立ち直るための日主別の過ごし方](/articles/shitsuren-tachinaori/)も読んでみてください。

## ふたりの相性を見てみる

気になる人や恋人との相性は、[相性占い](/shindan/)でふたりの生年月日を入れると無料で見られます。クリスマスまでにいい出会いがほしい人は、[クリスマスまでに×日主別の出会い方](/articles/xmas-deai/)もどうぞ。

## ぬくもりの伝え方に迷ったら

「彼はハグが苦手そう。どう伝えたらいい？」「付き合う前の人と、どこまで距離を縮めていい？」。そんな迷いは、誰かに相談すると、すっと答えが見えることがあります。電話占いでは、ふたりの相性や相手の気持ちを、占い師に具体的に聞くことができます。

寒い季節だからこそ、ぬくもりは心に残ります。自分らしい伝え方で、大切な人に気持ちを届けてください。
