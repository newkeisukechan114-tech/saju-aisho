「彼の気持ちが知りたい」「この恋、進めていい？」。迷ったときに、タロットカードを引いてみたことがある人も多いのではないでしょうか。

タロットは、日本でもっとも身近な占いのひとつです。いっぽう、韓国の占い「サジュ（四柱推命）」は、生年月日から生まれ持った気質や運の流れを読みます。同じ「占い」でも、ふたつは得意なことがまったく違います。

この記事では、タロットとサジュの違いを比べながら、両方を知っていると何がうれしいのか、どう掛け合わせるといいのかをまとめます。

## タロットとは？

タロットは、78枚のカードを使う占いです。寓意画が描かれた22枚の「大アルカナ」と、ワンド・カップ・ソード・ペンタクルの4つのスートからなる56枚の「小アルカナ」に分かれています。

もともとは占いの道具ではありませんでした。15世紀のイタリア北部で、カードゲームとして生まれたと考えられています。占いに使われるようになったのは18世紀の終わりごろで、1781年にスイス生まれの学者クール・ド・ジェブランが、タロットの絵柄に古代の知恵が隠されていると書いた本がきっかけとされています（この説自体には、学術的な根拠はありません）。

タロット占いでは、質問を心に思い浮かべながらカードを引き、出たカードの絵柄や向き、並びから答えを読み取ります。同じ人が同じことを聞いても、引くたびにカードは変わります。

## サジュとタロットの違い

| | サジュ | タロット |
|---|---|---|
| 分類 | 命術（生まれた日時で読む） | 卜術（その場で引いたカードで読む） |
| 使う情報 | 生年月日と生まれた時間 | 占いたい質問と、引いたカード |
| 結果 | 同じ人なら、いつ見ても同じ命式 | 引くたびに変わる |
| 得意なこと | 気質、相性、月・年・10年の運の流れ | いまの気持ち、相手の本音、近い未来の流れ |
| ひと言でいうと | <strong>「どんな人か」「いつ動くか」</strong> | <strong>「いま、どうするか」</strong> |

占いは大きく、生まれた日時を使う「命術」、その場の偶然を使う「卜術（ぼくじゅつ）」、手相や顔など形を見る「相術」に分けられます。サジュは命術、タロットは卜術の代表です。

いちばんの違いは、読める「時間の長さ」です。タロットは、いまの気持ちや、数週間から数か月ほどの近い流れを読むのが得意です。サジュは、生まれ持った気質と、月・年・10年ごとの運の流れまで、長い時間を見渡せます。

## 両方を知っていると、うれしい4つのこと

### 1. 「気持ち」と「時期」が、両方そろう

タロットで「彼もあなたに好意を持っている」と出ても、いつ動けばいいかまではわかりにくいものです。サジュで恋愛の運が高まる月を知っておけば、「気持ちはある。あとは、この月に誘ってみよう」と、具体的な一歩に変えられます。

### 2. 引くたびに変わる結果に、振り回されなくなる

タロットは、聞くたびに違うカードが出ます。不安なときほど何度も引いて、かえって迷ってしまうこともあります。サジュで「自分はもともとこういう気質」「いまはこういう時期」という土台を知っていると、カードの答えを落ち着いて受け止められます。

### 3. 相手の「本音」と「もともとの性格」を分けて見られる

タロットで読めるのは、いまの相手の気持ちです。サジュでは、相手の日主から、もともとの性格や恋愛の傾向がわかります。「最近そっけないのは、気持ちが冷めたから？それとも、もともと言葉が少ない人だから？」と、ふたつを分けて考えられます。

### 4. 迷ったときの「次の一手」が具体的になる

サジュで「今年は自分から動くといい年」とわかっていれば、タロットには「AとB、どちらの方法がいい？」と、具体的な選択を聞けます。大きな流れはサジュ、目の前の選択はタロット、という使い分けです。

## 日主別・タロットで聞くといい質問

タロットは、質問の仕方で答えの使いやすさが変わります。自分の日主の傾向に合わせて質問を選ぶと、カードの答えを行動に移しやすくなります。

| 日主 | 気質 | タロットで聞くといい質問 |
|---|---|---|
| 甲木（大樹） | まっすぐ、一途 | 「相手は、いま私に何を望んでいる？」 |
| 乙木（草花） | 協調的、合わせ上手 | 「私が本当に望んでいることは？」 |
| 丙火（太陽） | 明るく情熱的 | 「いま、相手のペースはどのくらい？」 |
| 丁火（灯火） | こまやか、思慮深い | 「気持ちを伝えるなら、どんな言葉がいい？」 |
| 戊土（山） | どっしり、頼られる | 「相手は、私に何を話したがっている？」 |
| 己土（田畑） | 面倒見がよい | 「私が自分を大切にするには？」 |
| 庚金（鋼） | 決断が早い、義理堅い | 「いま動くと、どんな流れになる？」 |
| 辛金（宝石） | 繊細、美意識が高い | 「この関係で、私が安心できることは？」 |
| 壬水（大海） | 自由、行動的 | 「この恋で、大事にしたほうがいいことは？」 |
| 癸水（雨露） | やさしい、感受性が豊か | 「相手の言葉の、本当の意味は？」 |

たとえば、乙木の人は相手に合わせすぎて、自分の気持ちが見えなくなりがちです。相手の気持ちより先に「私が本当に望んでいることは？」と聞いてみると、カードが自分の本音に気づかせてくれます。庚金の人は決断が早い分、動く前に「いま動くと、どんな流れになる？」と確かめると、勢いだけで進まずにすみます。

## 自分のサジュを調べてみる

自分の日主や、今月の運の流れは、[個人占い](/kojin/)で生年月日を入れると無料で調べられます。気になる人との相性は、[相性占い](/shindan/)で見られます。来年の運の流れは、[2027年の運勢（日主別）](/articles/2027-unsei-koboku/)からたどれます。

ほかの占いとの違いは、[サジュと四柱推命の違い](/articles/saju-shichusuimei-chigai/)、[MBTIとサジュの違い](/articles/saju-mbti/)、[サジュと動物占いの違い](/articles/saju-doubutsu-chigai/)、[アストロマップとサジュ](/articles/saju-astromap/)で紹介しています。

## タロットとサジュ、両方で見てもらうなら

電話占いには、タロットで今の気持ちを読む占い師と、四柱推命で運の流れを読む占い師がいます。両方を使える占い師も少なくありません。「サジュで見ると来月は恋愛の運がいい時期。彼の今の気持ちと、誘い方をタロットで見てほしい」といった聞き方をすると、ふたつの占いのいいところを一度に活かせます。

サジュで流れをつかみ、タロットで目の前の一歩を照らす。ふたつの占いを、迷ったときの道しるべにしてみてください。
