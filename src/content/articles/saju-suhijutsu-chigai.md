「運命数4の人は、まじめでコツコツ型」。雑誌やSNSで、数秘術の占いを見かけたことはありませんか。

数秘術は、生年月日の数字から占う占いです。じつは、韓国の占い「サジュ（四柱推命）」も、生年月日を使います。同じ誕生日から占うのに、数秘術とサジュでは、出てくる答えがまったく違います。

この記事では、ふたつの占いの違いを、実際の計算の例で比べます。そのうえで、両方を知っていると何がうれしいのか、どう掛け合わせればいいのかを紹介します。

## 数秘術とは？

数秘術（すうひじゅつ）は、数字には一つひとつ意味があるという考えにもとづく占いです。古代ギリシャの数学者ピタゴラスの考えがもとになったと言われますが、いま広く使われている形の数秘術は、20世紀に入ってから欧米で広まったものです。

もっとも有名なのは、生年月日の数字をすべてたして出す「運命数（ライフパスナンバー）」です。1から9までの数字に、11・22・33などの「マスターナンバー」を加えて読む流派が多く、運命数は、その人の人生のテーマや生き方の傾向を表すとされます。

- **数秘術**：1＋9＋9＋2＋5＋1＋4＝31、3＋1＝4。運命数は「4」です。
- **サジュ**：年は「壬申（みずのえさる）」、月は「乙巳（きのとみ）」、日は「庚寅（かのえとら）」。日の干の「庚」が、この人の日主（生まれ持った気質の中心）です。生まれた時間がわかれば、「時」の柱も加わります。

数秘術は、数字をたしてひとつの数にまとめます。サジュは、年・月・日・時をそれぞれ干支に置きかえ、木・火・土・金・水の五行のバランスを読みます。

## サジュと数秘術の違い

| | サジュ | 数秘術 |
|---|---|---|
| 生まれ | 中国の干支と陰陽五行の思想が、韓国で発展 | 古代ギリシャの数の思想がもとと言われ、20世紀に欧米で広まる |
| 使う情報 | 生年月日と、生まれた時間 | 生年月日（名前を使う流派もある） |
| 結果の数 | 日主だけで10タイプ、命式の組み合わせはとても多い | 運命数は1〜9とマスターナンバー |
| わかること | 気質、相性、月・年・10年の運の流れ | 人生のテーマ、個人年（1年ごとの流れ） |
| ひと言でいうと | <strong>「どんな人か」「いつ動くか」</strong> | <strong>「どう生きたいか」</strong> |

いちばんの違いは、結果のこまかさです。数秘術の運命数は、同じ数の人がたくさんいます。そのぶん、ひと目で「自分のテーマ」がつかみやすいのが長所です。サジュは、年・月・日・時の組み合わせで、同じ命式の人はぐっと少なくなります。そのぶん、性格のこまかな違いや、運の時期まで読めるのが長所です。

## 両方を知っていると、うれしい3つのこと

### 1. 「テーマ」と「気質」の両方から、自分がわかる

数秘術の運命数は「どう生きたいか」、サジュの日主は「生まれ持った気質」を表します。たとえば、運命数4（コツコツ積み上げる）で日主が庚金（決断が早い）の人なら、「決めたら早いけれど、本当は積み上げていく生き方に満足を感じる人」と読めます。ひとつの占いだけでは見えなかった、自分の中の両面に気づけます。

### 2. 同じ運命数の人とも、違いがわかる

運命数が同じ人どうしでも、日主が違えば、気質は違います。「同じ運命数4なのに、あの人と私はぜんぜん違う」と感じたことがあるなら、サジュの日主を比べると、その理由が見えてきます。

### 3. 「いつ動くか」まで見通せる

数秘術にも、1年ごとの流れを見る「個人年」があります。サジュでは、それに加えて月ごと・10年ごとの運の流れまで見られます。数秘術で今年のテーマをつかみ、サジュで動く月を選ぶ、という使い分けができます。

## 日主別・数秘術の結果をどう活かす？

数秘術の運命数を知ったら、自分の日主の気質と照らし合わせてみましょう。日主ごとに、運命数を活かすときのヒントをまとめました。

| 日主 | 気質 | 運命数を活かすヒント |
|---|---|---|
| 甲木（大樹） | まっすぐ、一途 | テーマに向かって、長い目で育てていく |
| 乙木（草花） | 協調的、合わせ上手 | 人と分かち合える形で、テーマを生かす |
| 丙火（太陽） | 明るく情熱的 | テーマを、人に伝えることで広げる |
| 丁火（灯火） | こまやか、思慮深い | 身近な人を照らす形で、テーマを生かす |
| 戊土（山） | どっしり、頼られる | テーマを、まわりの支えになる形で生かす |
| 己土（田畑） | 面倒見がよい | 自分のためにも、テーマを使ってみる |
| 庚金（鋼） | 決断が早い、義理堅い | 決めたテーマを、続ける工夫をする |
| 辛金（宝石） | 繊細、美意識が高い | 自分らしい美しさで、テーマを表現する |
| 壬水（大海） | 自由、行動的 | 新しい場所や人との出会いで、テーマを広げる |
| 癸水（雨露） | やさしい、感受性が豊か | 小さな積み重ねで、テーマを育てる |

たとえば、運命数がどの数でも、己土の人は人のために力を使いがちです。「自分のためにも、テーマを使ってみる」と意識すると、運命数の意味をより実感しやすくなります。

## 数秘術とサジュ、両方で見てもらうなら

電話占いには、数秘術や四柱推命など、いくつもの占術を使える占い師がいます。「数秘術の運命数は4、サジュの日主は庚金。この組み合わせで、来年はどう動けばいい？」と聞くと、ふたつの占いを重ねた、自分だけの答えにたどりつきやすくなります。

同じ誕生日でも、見る角度が変われば、新しい自分が見えてきます。数秘術とサジュを重ねて、自分らしい次の一歩を探してみてください。
