片思いの相手との相性が気になるとき、相手の**生年月日**がわかれば、韓国の四柱推命「サジュ」で相性を占えます。生まれた時間がわからなくても大丈夫です。

この記事では、生年月日だけで相性を占うしくみと、結果の読み方、そして相手の日主（生まれた日のタイプ）別のアプローチのしかたを紹介します。

## 生まれた時間がわからなくても大丈夫

サジュは本来、生まれた年・月・日・時間の4本の柱で見ます。でも、相手の生まれた時間まで知っていることはめったにありません。

時間がわからなくても、年・月・日の3本の柱で相性の大部分が見られます。とくに相性で大切な「**日主<strong>（生まれた日の天干）」と「</strong>日支**（生まれた日の地支）」は、生まれた日がわかれば出せます。

## 相手の生年月日を知るには

- **SNSのプロフィールや、誕生日のお祝いの投稿**から知る
- **会話の流れで聞く**：「誕生日いつ？」「何年生まれ？」は、自然に聞ける話題です
- **星座や干支の話から**：「何座？」「干支は？」と話題にすると、誕生日に話がつながりやすくなります

無理に聞き出したり、こっそり調べたりするのはやめましょう。相手が知られたくないこともあります。

## 結果の読み方

[相性占い](/shindan/)では、次の4つの観点で相性を読み解きます。

| 観点 | 片思いのときの見どころ |
|---|---|
| 日主の結びつき | 惹かれ合いやすい組み合わせか、どちらが支える側になりやすいか |
| 暮らしのリズム | 一緒に過ごしたときに楽な関係か |
| 干支の相性 | 共通の話題や、まわりの人との関係 |
| 五行の補い合い | お互いに足りない力を持っているか |

相性の点数より大事なのは、**ふたりがつまずきやすいポイント**です。たとえば「進展がゆっくりになりやすい」と出たら、焦らずに少しずつ距離を縮めればいい、ということ。結果は、アプローチのしかたを考えるヒントとして使いましょう。

## 相手の日主別・アプローチのしかた

相手の日主がわかったら、その人が「うれしい」と感じるポイントに合わせて近づいてみましょう。

| 相手の日主 | うれしいポイント | 近づき方のヒント |
|---|---|---|
| [甲木](/articles/koboku/)（大樹） | 努力を認められること | 頑張っていることを具体的にほめる |
| [乙木](/articles/otsuboku/)（草花） | 気持ちを聞いてもらえること | 「どう思う？」と意見を聞く |
| [丙火](/articles/heika/)（太陽） | 一緒に楽しめること | 楽しそうに話を聞き、笑顔で反応する |
| [丁火](/articles/teika/)（灯火） | 小さな変化に気づいてもらえること | 髪型や持ち物の変化に気づいて伝える |
| [戊土](/articles/bodo/)（山） | 頼られること | ちょっとした相談をしてみる |
| [己土](/articles/kido/)（田畑） | 感謝されること | してもらったことに、ていねいにお礼を |
| [庚金](/articles/koukin/)（鋼） | 約束を守ること | 小さな約束をきちんと守る |
| [辛金](/articles/shinkin/)（宝石） | センスをほめられること | 選んだものや服装をほめる |
| [壬水](/articles/jinsui/)（大海） | 知的な刺激があること | 新しい話題やおすすめを共有する |
| [癸水](/articles/kisui/)（雨露） | 気持ちをわかってもらえること | 言葉の奥の気持ちをくみとって返す |

自分の日主は、[個人占い](/kojin/)で調べられます。自分の傾向（たとえば、合わせすぎる、勢いで動くなど）を知っておくと、片思いの悩みが少し軽くなります。

## 結果別・次の一歩

- **惹かれ合いやすいと出たら**：チャンスです。共通の話題をきっかけに、ふたりで話す時間を少しずつ増やしてみて。
- **刺激し合う関係と出たら**：違いが魅力になる組み合わせ。相手のペースを尊重しながら、自分らしさも見せて。
- **点数が低めでも**：相性は、関係を決めるものではありません。つまずきやすいところを先に知っておけば、すれ違いを防げます。

## 気をつけたいこと

- 相手の生年月日を、無理に聞き出したり調べたりしない
- 相性の結果は、相手の気持ちそのものではない
- 結果が悪くても、自分を責めない

相手が今どう思っているか、この先どう動けばいいかを知りたいときは、結果をもとに信頼できる人に相談してみるのもひとつの方法です。クリスマスに向けた動き方は「[クリスマスまでに恋人がほしい人へ](/articles/xmas-deai/)」でも紹介しています。
