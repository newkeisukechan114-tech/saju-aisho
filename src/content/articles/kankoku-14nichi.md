韓国の恋人たちにとって、記念日はバレンタインデーだけではありません。韓国では<strong>毎月14日が「恋人の日」</strong>とされていて、月ごとにテーマのある記念日があります。

手帳を贈り合う日、バラを贈る日、恋人がいない人どうしで黒い麺を食べる日まで。この記事では、12か月の「14日」をまとめて紹介し、後半では韓国の占い「サジュ（四柱推命）」の日主（生まれた日のタイプ）別に、あなたに似合う14日を選びました。

## 韓国の「14日」記念日・12か月一覧

| 日付 | 記念日 | どんな日？ |
|---|---|---|
| 1月14日 | ダイアリーデー | 新しい手帳を贈り合い、ふたりの記念日を書きこむ日。キャンドルを贈る「キャンドルデー」とも |
| 2月14日 | バレンタインデー | 女性から男性へ、チョコレートで気持ちを伝える日 |
| 3月14日 | ホワイトデー | 男性から女性へ、キャンディなどでお返しをする日 |
| 4月14日 | ブラックデー | 恋人のいない人どうしが黒い服を着て、ジャージャー麺（짜장면）を食べる日 |
| 5月14日 | ローズデー | 恋人にバラの花を贈る日 |
| 6月14日 | キスデー | 恋人どうしがキスをする日 |
| 7月14日 | シルバーデー | 銀のアクセサリーやペアリングを贈る日 |
| 8月14日 | グリーンデー | 森や公園など、緑の中でゆっくり過ごす日 |
| 9月14日 | フォトデー | ふたりの写真を撮って残す日。カラオケで歌う「ミュージックデー」とも |
| 10月14日 | ワインデー | ワインで乾杯する日 |
| 11月14日 | ムービーデー | いっしょに映画を観る日 |
| 12月14日 | ハグデー | 寒い季節に、ハグでぬくもりを伝える日 |

呼び方や過ごし方には地域や世代による違いがあり、すべての日を祝うカップルばかりではありません。実際に広く祝われているのは、2月・3月のほか、11月11日の[ペペロデー](/articles/pepero-day/)やクリスマスなど一部の日です。「毎月なにかしら理由をつけて、ふたりの時間を楽しむ」という、ゆるやかな文化だと考えるとちょうどいいでしょう。

おもしろいのは、2月から4月の流れです。2月のバレンタインで女性が気持ちを伝え、3月のホワイトデーで男性が応える。そして<strong>どちらにも縁がなかった人どうしが、4月のブラックデーに集まって黒いジャージャー麺を食べる</strong>、というオチがついています。

いまではブラックデーも「さみしい日」というより、ひとりの人どうしで気軽に楽しむイベントとして定着しています。恋人がいてもいなくても、だれかと過ごす口実になるのが、韓国の14日のいいところです。

## 日主別・あなたに似合う「14日」

サジュでは、生まれた日の天干（日主）で、その人の性質を10タイプに分けます。自分の日主がわからない人は、[個人占い](/kojin/)に生年月日を入れるとすぐにわかります。

### 甲（きのえ）｜大樹タイプ → 1月のダイアリーデー
目標に向かってまっすぐ伸びる甲の人は、計画を立てるほど力が出るタイプ。ふたりの一年の予定を手帳に書きこむダイアリーデーは、関係を育てるのにぴったりです。→ [甲木の性格と恋愛](/articles/koboku/)

### 乙（きのと）｜草花タイプ → 5月のローズデー
やさしく、相手に寄りそう乙の人。言葉にするのが照れくさい気持ちも、花ならすっと渡せます。→ [乙木の性格と恋愛](/articles/otsuboku/)

### 丙（ひのえ）｜太陽タイプ → 9月のフォトデー
いるだけで場が明るくなる丙の人は、笑顔の写真がいちばんの記念品。ふたりの写真を残す日にしましょう。→ [丙火の性格と恋愛](/articles/heika/)

### 丁（ひのと）｜灯火タイプ → 6月のキスデー
静かで一途な情熱を持つ丁の人。にぎやかなイベントより、ふたりきりで気持ちを確かめ合う日が似合います。→ [丁火の性格と恋愛](/articles/teika/)

### 戊（つちのえ）｜山タイプ → 8月のグリーンデー
どっしりと落ちついた戊の人は、自然の中でこそ素の自分に戻れます。公園や森でのんびり過ごすデートを。→ [戊土の性格と恋愛](/articles/bodo/)

### 己（つちのと）｜田畑タイプ → 12月のハグデー
人を育て、包みこむ己の人。言葉よりも、そばにいるぬくもりで安心を伝えるタイプです。→ [己土の性格と恋愛](/articles/kido/)

### 庚（かのえ）｜鋼タイプ → 7月のシルバーデー
約束を大切にする庚の人には、銀のペアリングがよく似合います。「決めたら守る」気持ちを形にする日に。→ [庚金の性格と恋愛](/articles/koukin/)

### 辛（かのと）｜宝石タイプ → 10月のワインデー
美意識の高い辛の人は、すこし特別なお店でのワインの乾杯がしっくりきます。グラス選びから楽しんで。→ [辛金の性格と恋愛](/articles/shinkin/)

### 壬（みずのえ）｜大海タイプ → 11月のムービーデー
発想のスケールが大きい壬の人は、物語の世界に浸るのが好き。観たあとに感想を語り合う時間まで、デートの一部です。→ [壬水の性格と恋愛](/articles/jinsui/)

### 癸（みずのと）｜雨露タイプ → 1月のダイアリーデー
気持ちを察するのが得意な癸の人は、言葉を書いて残すのが似合います。手帳に、相手への小さなメッセージをしのばせて。→ [癸水の性格と恋愛](/articles/kisui/)

## ふたりの相性も見てみる

記念日をいっしょに過ごしたい相手がいるなら、ふたりの相性も気になるところ。[相性占い（ふたり用）](/shindan/)では、ふたりの生年月日から、五行の相性と4つの読み解きを無料で出せます。

## まとめ

- 韓国では、毎月14日が恋人たちの記念日。ダイアリーデーからハグデーまで、12か月それぞれにテーマがあります。
- 2月・3月・4月は「伝える・応える・ひとりどうしで楽しむ」の3つでひとまとまり。
- 日主ごとに似合う14日はちがいます。まずは[個人占い](/kojin/)で自分の日主を確かめて、次の14日の過ごし方を決めてみてください。
